# QA 问答客户问题清单（ChatBI 新客户关切）

## 使用说明
- 站在首次接触 ChatBI 的客户视角，聚焦决策所需的核心信息；按场景执行以覆盖功能、成本、安全、上线风险。
- 提问时记录所用配置（project_name/缓存/阈值），便于比对命中与日志表现。

## 场景 A：产品价值与适用场景
1. ChatBI 能为我们业务带来什么具体收益？有没有行业内的成功案例？
2. 对零售/制造/金融等不同行业，默认支持的典型场景有哪些？
3. 如果没有现成知识库，只用现有 PPT/文档，能多快搭出可用问答？

## 场景 B：功能与体验
4. 用户可以通过哪些入口提问（Web、移动、钉钉/企业微信、内嵌组件）？
5. 支持多轮对话和追问吗？能否引用来源页号或原文片段？
6. 对模糊问题或拼写错误（中英文混输）系统如何处理？

## 场景 C：数据安全与合规
7. 我们的数据会不会上传到第三方？默认的数据存储位置在哪里？
8. 是否支持私有化部署或 VPC 隔离？密钥与访问控制怎么做？
9. 敏感字段（如客户姓名、合同金额）能否自动脱敏？日志里会不会留存明文？

## 场景 D：集成与上线
10. 和现有知识库/文档管理/CRM/ERP 如何集成？有无标准 API 或 SDK？
11. 知识库更新后，向量索引多久能同步？是否需要停机重建？
12. 前端样式可以自定义吗？支持多语言界面和问答吗？

## 场景 E：成本与 ROI
13. 计费方式是什么（按调用量/席位/并发）？有没有最低采购量或试用期？
14. 平均每次问答的模型成本是多少？缓存能节省多少费用？
15. 需要投入多少人力维护？上线到稳定运行的典型周期是多久？

## 场景 F：性能与可靠性
16. 单次问答的典型响应时间是多少？高峰期会不会变慢？
17. 断网或第三方模型不可用时，系统如何降级？会影响在线用户吗？
18. 有哪些可观测指标（命中率、延迟、错误率）和告警方式？

## 场景 G：运维与支持
19. 遇到回答不准时，业务团队如何自助调优？有无可视化的反馈或标注工具？
20. 提供哪些支持服务（SLA、响应时间、值班方式）？升级迭代的节奏和变更通知渠道是什么？

## 记录要点
- 对每个问题记录：时间、配置（项目/缓存/阈值/采样）、命中状态、cache_status、语义得分（如有）。
- 若命中缓存，确认回答是否标注来源或生成时间；若失败，记录错误提示与日志状态。
