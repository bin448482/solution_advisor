# QA 问答客户问题清单（ChatBI 新客户关切）

## 使用说明
- 站在首次接触 ChatBI 的客户视角，聚焦决策所需的核心信息；按场景执行以覆盖功能、成本、安全、上线风险。
- 提问时记录所用配置（project_name/缓存/阈值），便于比对命中与日志表现；示范回答可作为命中与准确性的对照答案。

## 场景 A：产品价值与适用场景
1. 问：ChatBI 能为我们业务带来什么具体收益？有没有行业内的成功案例？
   答：可将内部文档/PPT 变成可检索问答，常见收益是资料搜集与答疑时间下降 30–60%，新人培训周期缩短；零售商品知识、制造设备维护、金融产品合规等场景有成功落地案例。
2. 问：对零售/制造/金融等不同行业，默认支持的典型场景有哪些？
   答：零售（商品咨询、促销规则、导购脚本）、制造（设备手册、故障排查 SOP）、金融（产品说明、合规条款提示）、政务/地产（政策检索、流程指引）等均有模板与提示语预设。
3. 问：如果没有现成知识库，只用现有 PPT/文档，能多快搭出可用问答？
   答：支持直接导入 PPT/文档并自动切片向量化；小型资料可在 10–30 分钟内完成索引，导入完成后即可提问。

## 场景 B：功能与体验
4. 问：用户可以通过哪些入口提问（Web、移动、钉钉/企业微信、内嵌组件）？
   答：提供 Web 控制台、可嵌入的前端组件（iFrame/JS SDK）、企业微信/钉钉机器人，以及 REST/SDK 供自有前端集成。
5. 问：支持多轮对话和追问吗？能否引用来源页号或原文片段？
   答：支持多轮对话与追问；回答可附来源页号/段落摘要，可配置“必须引用证据”模式。
6. 问：对模糊问题或拼写错误（中英文混输）系统如何处理？
   答：会做规范化与语义匹配，轻微错别字仍可命中；置信度低时会给出澄清或候选检索结果。

## 场景 C：数据安全与合规
7. 问：我们的数据会不会上传到第三方？默认的数据存储位置在哪里？
   答：默认私有或 VPC 内部署，向量库与日志存放在客户侧；不会将业务数据上传到公有第三方模型，除非显式配置外部 API。
8. 问：是否支持私有化部署或 VPC 隔离？密钥与访问控制怎么做？
   答：支持裸机/VM/K8s 私有化与 VPC 隔离；API Key/Token + RBAC，并可对接企业 SSO（OIDC/SAML）。
9. 问：敏感字段（如客户姓名、合同金额）能否自动脱敏？日志里会不会留存明文？
   答：可配置入库与日志的脱敏/哈希；默认可关闭记录完整 prompt/context，避免敏感信息明文落盘。

## 场景 D：集成与上线
10. 问：和现有知识库/文档管理/CRM/ERP 如何集成？有无标准 API 或 SDK？
    答：提供 REST API 与 Python/JS SDK；支持从文档库、CRM/ERP 拉取数据，亦可用 Webhook 触发增量刷新。
11. 问：知识库更新后，向量索引多久能同步？是否需要停机重建？
    答：支持增量切片与索引更新，小批量通常分钟级完成，无需停机；全量重建可后台并行，前端无感。
12. 问：前端样式可以自定义吗？支持多语言界面和问答吗？
    答：嵌入组件支持主题/配色/Logo 自定义；支持中英双语，其他语言可通过翻译中间层或多模型配置。

## 场景 E：成本与 ROI
13. 问：计费方式是什么（按调用量/席位/并发）？有没有最低采购量或试用期？
    答：常见按调用量或实例规格/并发计费，企业版通常提供试用额度；最低采购量与合同约定相关。
14. 问：平均每次问答的模型成本是多少？缓存能节省多少费用？
    答：成本取决于所选模型与上下文长度；开启精确缓存后，重复问题可减少 30–60% 的模型调用费用（语义缓存已下线）。
15. 问：需要投入多少人力维护？上线到稳定运行的典型周期是多久？
    答：通常 1–2 人可维护；从接入到稳定上线约 1–3 周，取决于文档准备与系统集成范围。

## 场景 F：性能与可靠性
16. 问：单次问答的典型响应时间是多少？高峰期会不会变慢？
    答：本地或专线环境下单轮 1–3 秒（检索 <1s，LLM 取决于模型）；高峰期可依靠并发池与缓存保持稳定。
17. 问：断网或第三方模型不可用时，系统如何降级？会影响在线用户吗？
    答：可回退到检索摘要或兜底文案；模型失败时返回清晰提示并记录日志，不阻塞前端请求。
18. 问：有哪些可观测指标（命中率、延迟、错误率）和告警方式？
    答：提供命中率、延迟、错误率、缓存命中率、模型调用次数等指标；支持日志导出与 Prometheus/OTel 接入告警。

## 场景 G：运维与支持
19. 问：遇到回答不准时，业务团队如何自助调优？有无可视化的反馈或标注工具？
    答：支持在控制台/标注工具对答案打标、编辑或固定答案；可调整阈值、重索引并回放验证。
20. 问：提供哪些支持服务（SLA、响应时间、值班方式）？升级迭代的节奏和变更通知渠道是什么？
    答：可提供企业级 SLA（如 8x5 或 7x24），响应时长按合同约定；小版本通常按月发布，变更前发送通知与说明。

## 记录要点
- 对每个问题记录：时间、配置（项目/缓存/阈值/采样）、命中状态、cache_status（无语义得分字段）。
- 若命中缓存，确认回答是否标注来源或生成时间；若失败，记录错误提示与日志状态。
