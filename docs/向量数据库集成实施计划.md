# 向量数据库集成实施计划

## 概述

将 Chroma 向量数据库与 M3E 本地中文 Embedding 模型集成到现有 PPT 解析流水线中，实现：
1. **Pipeline 集成**：PPT 处理完成后自动插入向量库
2. **独立脚本**：批量导入、重建索引、集合管理

## 技术选型

- **向量数据库**：Chroma（轻量级、本地持久化）
- **Embedding 模型**：M3E-base（768维、中文优化、本地运行）
- **集成方式**：双模式（Pipeline 自动 + CLI 手动）

## 错误处理策略

### 重试逻辑
- **模型下载失败**：3 次重试 + 指数退避
- **OOM 错误**：自动减半 batch_size，重试 1 次
- **向量库连接失败**：3 次重试 + 5 秒延迟
- **重复 ID**：跳过并警告（幂等性）

### 部分失败处理
- Pipeline 模式：向量库失败不中断流程，记录错误
- 独立脚本：继续处理剩余文档，输出失败摘要
- 失败文档写入错误日志文件

### Manifest 更新
新增错误阶段：
- `vectordb_init`：模型加载或连接失败
- `vectordb_embed`：向量生成失败
- `vectordb_insert`：文档插入失败

新增指标字段：
```python
class VectorDBMetrics(BaseModel):
    documents_inserted: int
    documents_failed: int
    embedding_time_seconds: float
    insertion_time_seconds: float
    collection_name: str
```

## 配置调优建议

### 模型选择
- **m3e-base**（768维，~400MB）：推荐，速度与精度平衡
- **m3e-large**（1024维，~1.2GB）：更高精度，推理较慢

### 设备选择
- **cpu**：通用，速度较慢（~2-5秒/批次）
- **cuda**：需 NVIDIA GPU，快 10-20 倍
- **mps**：Apple Silicon GPU，快 5-10 倍

### Batch Size 调优
- CPU：16-32（平衡速度与内存）
- GPU：64-128（充分利用显存）
- 根据可用 RAM/VRAM 调整
